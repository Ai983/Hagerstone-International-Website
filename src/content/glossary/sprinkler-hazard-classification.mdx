## Why it matters

The hazard class is the first input to a sprinkler design. It decides how much
water must be discharged, over what area, for how long — which sizes the pump
room and the fire water tank before any pipe is drawn.

## How it works in practice

| Class | Typical occupancies | Effect on design |
| --- | --- | --- |
| Light hazard | Offices, hospitals, hotels | Lowest water density |
| Ordinary hazard | Manufacturing, retail, some storage | Higher density and area |
| High hazard | High-piled storage, flammable materials | Highest demand |

## Common mistakes

- **Designing for today's use only.** A change of use can outgrow the system.
- **Ignoring storage height.** Racking height changes the hazard significantly.
- **Sizing the tank before the class is fixed.** The tank depends on it.
